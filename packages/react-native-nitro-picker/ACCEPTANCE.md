# 验收清单

代码测试、项目构建与设备运行须取得用户明确授权。静态检查不能证明原生编译或视觉/手势行为正确。

## 静态检查

- `tsc --noEmit`：公开接口、演示页及 worklet 类型。
- ESLint：仅本包手写 JS/TS、演示页、必要的根配置改动。
- Nitrogen / Fabric codegen：生成双端接口，核对实现签名、事件结构及自动链接引用。
- Diff 检查：不改动生成文件，不更改原有应用启动入口。

## 双端运行验收（Android 本轮记录见下，iOS 未执行）

在包含新增子包的新原生客户端打开 `/picker-tests`（独立操作与事件日志）或 `/picker-demo`（展示），Android / iOS 分别验证：

1. 单列初始项居中；首尾均可居中；轻拖、快速甩动和惯性途中再次拖动后，最终索引与正面选项一致。
2. 上下项跟随圆柱曲面转动；图片及文字共同变换；无边缘裁切、串内容或滚动闪烁。
3. 变更顺序为 start → change（仅索引变化时）→ end；拒绝变更恢复原值；程序选末项不产生用户事件。
4. 双列同时滑动；左列变化后右列内容及索引更新，旧滚动事件不能覆盖新值；无关列的普通父组件重渲染不打断滚动。
5. 缩短、清空、恢复、同数量替换及重排选项；越界、缺省索引和空列均符合 README；非法索引、行高报错。
6. 滚动中切换禁用、更新受控值、改变尺寸或卸载；惯性停止、资源释放，无迟到回调或崩溃。重新挂载可正常使用。
7. 列宽覆盖、横竖屏、深浅主题、定制背景与遮罩；遮罩不阻挡触摸。
8. 系统减少动态效果开启时使用平面滚轮；运行中切换设置及时生效。
9. 外层 ScrollView 与列手势协调；VoiceOver / TalkBack 读出列标签与选中项，增减操作居中、回调正确，空列与禁用状态不可调整。

## 审查修复项
